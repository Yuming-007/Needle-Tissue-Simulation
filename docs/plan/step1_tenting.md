## 0. 这一步证明什么，不证明什么
- **证明**：针尖和组织表面之间的**单边接触机制**在 SOFA 里正确工作：
  - 只推不拉；
  - 接触力的方向、大小和作用位置正确；
  - 力能正确读出，作用力 = 反作用力；
  - 不依赖 dt；
  - 实时。
- **不证明**：
  - 组织"应该"有多硬。在 h = 10 mm 的网格上，针尖的局部刚度本来就由网格决定（见 §1.3），这一步只验证接触机制，不标定刚度；
  - 刺穿（第 2 步）、摩擦（第 4 步）、针身和表面的接触。
- 第 1 步的针始终沿 −z 竖直插入，表面是平的顶面。斜插、曲面留到以后。

## 1. 物理

### 1.1 现象
针尖接触组织表面后继续前进，组织被压出一个凹坑（tenting），针受到的阻力随压入深度增加，直到达到刺穿条件（第 2 步）。刺穿前针尖和组织之间：
- 只有压力，没有拉力：针后退时组织回弹，不会被"粘"住；
- 第 1 步按**无摩擦**处理：切向不传力；
- 针尖不会进入组织内部（不穿透）。

### 1.2 数学描述：Signorini 接触条件〔原文：Duriez 2006；方法手册 §2〕
记 g 为针尖到组织表面的法向距离（g > 0 表示分开），λ_n 为法向接触力（压力为正）：
$$g\ge 0,\qquad \lambda_n\ge 0,\qquad g\,\lambda_n=0$$
- 分开时没有力（g > 0 ⇒ λ_n = 0）；有力时必然贴合（λ_n > 0 ⇒ g = 0）。
- SOFA 的约束法每一步求解这个互补问题：先算"如果没有接触，组织会在哪里"（自由运动），再求最小的 λ_n ≥ 0，使修正后的 g ≥ 0。

### 1.3 针尖比单元小得多时，力–深度关系由什么决定〔推导〕
- 连续体里，**理想的点载荷**作用在半空间上，载荷点下方的位移是无穷大（Boussinesq 解：位移 ∝ F/(E·r)）。所以"一个点压进连续体"的刚度 F/δ = 0。
- 真实的针尖有有限的尺寸（18 G 针外径约 1.27 mm），刚度量级约为 2aE/(1−ν²)，其中 a 是针尖的接触半径。
- 有限元里，针尖接触的是一个表面点（重心插值到 3 个节点），力实际上分布在一个约一个单元大小的区域上。所以离散模型的刚度量级约为 E·h，并且**随网格变化**（网格越细越软）。0a-2 已经量化过平底压头的这种网格依赖。
- **结论**：h = 10 mm 网格上的 tenting 刚度是离散量，不是物理量。第 1 步只能验证"接触机制正确地施加了约束"，验证的参照必须是**同一网格、同一离散接触雅可比**上的结果（ChatGPT 复核后加入的要求，`00_start_plan.md`）。物理上合理的 tenting 刚度怎么得到（针尖面积的建模、按实验标定、网格加密），留到第 2 步（刺穿阈值依赖它）和第 4.5 步（加密网格）再处理。
- 文献中的刺穿前曲线：Okamura 2004 测得牛肝刺穿前的力约为 a₁z + a₂z²（二次上升）〔原文〕。方法手册 §5.1 推导过：线弹性材料下，这种非线性主要来自几何非线性（大变形、大转动）〔推导〕。我们的共旋模型可以表示几何非线性，但这一步不要求定量吻合。

### 1.4 插件里的实现（准备复用的部分）〔代码〕
- 刺穿前，`InsertionAlgorithm` 找针尖到组织外表面的最近点，输出一对接触点交给 `ConstraintUnilateral`（`docs/code/01` §1）。
- `ConstraintUnilateral`：mu = 0 时每个接触点 1 行约束；局部求解 `UnilateralConstraintResolution::resolution`：λ ← λ − d/W，再截断到 [0, maxForce]（`UnilateralResolution.h`）。
- 约束方向有两种可选：
  - `ContactDirection`：mainDir = (针上的点 − 组织上的点) 归一化；如果它和"组织表面法向取反"的点积 ≤ ε，就改用表面法向取反（`ContactDirection.h`）；
  - `SecondDirection`：直接用组织表面法向取反（`SecondDirection.h`）。
- 违反量 δ = n·(P_第一个点 − P_第二个点)，第一个点在针上（0c 约定）。法向朝外还是朝里、δ 的正负怎样对应穿透，取决于表面三角形的朝向和法向组件（Phong / Gouraud），**这一步用实际场景确认**（0c 待确认项）。

## 2. 预测（第②步：事先写下可以检验的结论）

| 编号 | 预测 | 依据 | 判据 |
|---|---|---|---|
| P1 | **顶点接触 = 同一顶点的给定位移**：针尖正对顶面中心节点（重心坐标 (1,0,0)，法向 = z，位置对称），以 1 mm/s 压入 δ = 0–10 mm。接触约束得到的力–深度曲线，和"同一节点只给定 z 向位移、x/y 自由"的曲线一致 | 两者是同一个离散问题〔推导〕 | 准静态段相对差 ≤ 1e-6（R1、同一 dt、同一速度）；大变形（δ = 10 mm）时也成立 |
| P2 | **三角形内部接触 = 同一雅可比的参照**：针尖对准某个三角形内部的点（权重 w），小压深下的刚度 = k_ref = 1/(wᵀCw)，C 是三个节点之间的 z 向柔度矩阵（用静力解分别在三个节点上加单位 z 向力得到） | 同一个离散接触雅可比〔推导〕 | 小压深（δ ≤ 0.5 mm）刚度相对差 ≤ 1% |
| P3 | **单边性和正负号**：接触前 λ = 0、没有力；接触后 λ > 0，组织被向下推，针受 +z 方向的阻力；针后退时组织回弹，λ 回到 0，没有粘连 | Signorini 条件 | 接触前 \|F\| = 0；后退到分开时 λ = 0，组织恢复到静止位置 |
| P4 | **作用力 = 反作用力**：准静态时，针根力 = −（约束作用在组织上的合力）= −（组织底面反力） | 同一个 λ；平衡 | 相对差 ≤ 1e-6（前两者）；和底面反力相对差 ≤ 0.5%（准静态） |
| P5 | **dt 和速度无关**：dt = 0.005 / 0.01 / 0.02，v = 1 / 5 mm/s 下，准静态段的力–深度曲线一致 | 0a-3 的结论 | 起步瞬态之后相对差 ≤ 1%（5 mm/s） |
| P6 | **约束方向正确且稳定**：每步记录约束方向 n，平顶面上应恒为 ±z。用 `ContactDirection` 时，贴合后两点距离约为 0，方向可能被数值噪声主导（§1.4） | 〔代码〕推论 | n 和 z 轴的夹角 ≤ 1e-6 rad；若不满足，改用 `SecondDirection` 并重测 |
| P7 | **接触点不漂移**：顶点接触时，接触点保持在中心节点（对称）；三角形内部接触时，记录组织变形引起的接触点漂移（无摩擦，组织可以在针尖下横向移动） | 对称性；无摩擦 | 顶点：漂移 ≤ 1e-9 m；内部：只记录 |
| P9 | **网格依赖（静态，固定压深）**：P1 通过后，"顶点接触" ≡ "给同一顶点施加位移"，所以 P9 直接给中心节点施加若干固定压深的位移，做静力求解，不需要接触和动态轨迹。全模型：h = 10、5 mm；h = 2.5 mm 用四分之一对称模型（中心节点在两个对称面上，0a-2 已验证，约 2.9 万自由度，几分钟）。压深 h = 10 / 5 mm 取 1、5、10 mm，h = 2.5 mm 只取 1、2、5 mm（避免单元严重扭曲），并记录最差单元的质量。预计针尖是一个点时，刚度随网格加密持续下降、不收敛（Boussinesq 点载荷奇异性） | 〔推导〕 | 只记录趋势和量级（三个网格才能判断收敛与否），作为第 1.5 步设计针尖表示和加密参数的依据；真正的 2–3 mm 局部分辨率在第 1.5 步的非均匀网格上验证 |
| P8 | **实时**：只有 1 行约束，R3 下每步耗时接近 W1 | 0d | p95 ≤ dt |
- 量级估计〔推论〕：0a-2 中 5 个节点（a_eff = 12.6 mm）的压头，在 ν = 0.45、h = 10 mm 时刚度约 177 N/m。单个顶点受力应明显更软，估计在几十 N/m 量级，所以 δ = 10 mm 时力约在 0.3–1 N。这只是量级，不作为判据。

## 3. 最小场景（第③步的计划）
- 组织：8 cm 立方体，n = 9，底面固定，侧面和顶面自由，重力关闭。验证用 R1，最后做一次 R3 一致性检查。
- 针：纯运动学，竖直（针轴 −z），针尖从顶面中心节点正上方 **1 mm** 处开始。不从 0 距离开始，避免 `ContactDirection` 在两点重合时对零向量归一化（§1.4）。以 v 下压到 δ = 10 mm，保持，再后退到分开。
- 接触（2026-10-01 和用户确定）：**A1（插件的检测 + `ConstraintUnilateral`）是唯一的主实现**，刺穿阈值设为无穷大（第 1 步不刺穿），针身碰撞关闭或确认不会触发。具体组件组合在第③步读插件场景后确定，写进场景说明。
- 主要验证：同一网格、同一雅可比的给定位移参照（P1、P2）。
- A2（SOFA 自带的拉格朗日接触）只做**一个顶点接触工况的轻量检查**，不搭第二套完整实现；接触配置参考 probe–tissue 教程（`docs/resources/inventory.md`）。
- 参照场景（P1）：同一组织、同一求解器和 dt，中心节点用 `PartialFixedProjectiveConstraint [0,0,1]` 加 z 向速度驱动（和 0a-3 的压头相同的方法，只是 1 个节点）。
- 参照计算（P2）：静力求解得到三个节点之间的 3×3 柔度矩阵 C，计算 k_ref = 1/(wᵀCw)。
- 读数：针根力（`common.needle_wrench`）、约束作用在组织上的力（组织侧的 J 和 λ）、底面反力（动力学中读 `force`）、约束方向 n、接触点位置。
