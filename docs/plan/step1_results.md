# 第 1 步（tenting）：实验结果（第③④⑤步）

- 日期：2026-10-01。设计和预测见 `step1_tenting.md`；实现方式调研见 `step1_tenting_survey.md`。
- 脚本：`scenes/contact.py`（插件接触的构建函数）、`scenes/step1/t1_vertex.py`、`t1_interior.py`、`t1_mesh_dependence.py`、`t1_timing.py`、`t1_a2_check.py`、`t1_gui_scene.py`；数据在 `results/step1/`。
- 测试台：8 cm 立方体，n = 9（h = 10 mm），**swapping=True**（见发现 1），FTCfix polar，ν = 0.45，E = 5 kPa，底面固定，重力关闭；验证用 R1（`SparseLDLSolver`），dt = 0.01 s，不加 Rayleigh。
- 针：纯运动学，竖直；接触：插件 A1（`InsertionAlgorithm`，刺穿阈值不设 = 无穷大，`enableShaftCollision=False`、`enableInsertion=False`；`ConstraintUnilateral` + `SecondDirection` + `PhongTriangleNormalHandler`；表面由 `Tetra2TriangleTopologicalMapping` 提取，`IdentityMapping` 挂到组织上），组件组合参照插件官方场景。

> **⚠️ 限制（2026-10-01 加入，ChatGPT 复核建议）**：本文件和 GUI 场景里的具体力值（例如压深 5 mm 时 0.323 N、10 mm 时 0.519 N）**只是粗测试台（h = 10 mm 规则网格、点接触、共旋线弹性、ν = 0.45 验证用参数）上接触机制的数值输出，不具有物理定量意义**。点接触的力强烈依赖网格和针尖落点（发现 4、5），10 mm 压深对 10 mm 单元也是很大的局部变形。不能在报告或演示中把它们说成"真实的 tenting 力"。第 1 步验证的是接触**机制**，不是组织刚度。

## 预测检验结果

| 编号 | 内容 | 结果 | 判定 |
|---|---|---|---|
| P1a | 顶点接触（插件单边约束）vs SOFA 自带双边约束直接连到中心节点（同一动力学，逐步比较组织受力） | 最大相对差 **6.8e-15**；双边约束 x、y 分量 ≤ 1.2e-17 | ✓ |
| P1b | 准静态（1 mm/s）针根力 vs 同一网格的静力解 F_static(δ) | 起步 0.2 s 之后最大 2.0%（起步瞬态），平均 +0.26%；压深 ≥ 2 mm 时 ≤ 0.34%（见 P5） | ✓ |
| P2 | 三角形内部接触 vs 同一雅可比参照 k_ref = 1/(wᵀCw)（3 个点 + 中心顶点对照，压深 0.01–0.05 mm） | 相对差 **−0.04% 到 −0.05%**（顶点对照同样 −0.05%） | ✓ |
| P3 | 单边性 | λ ≥ 0 全程成立；针尖在未变形表面之上时 λ = 0；慢速后退结束后中心节点回到静止位置（偏差 3e-15 m）；快速后退（1 m/s）时组织和针尖分离，针尖在表面之上的 201 步 λ 全为 0，组织回弹冲过静止位置 0.555 mm 后回到静止 | ✓ |
| P4 | 作用力 = 反作用力 | \|F_针 + F_组织\| / \|F_针\| ≤ 4.3e-16；保持阶段底面反力和针根力相差 5.4e-6 | ✓ |
| P5 | dt（0.005 / 0.01 / 0.02）和速度（1 / 5 mm/s）无关 | 压深 ≥ 2 mm 时相对静力解最大 0.32%–0.67%，平均 +0.15% 到 +0.47% | ✓ |
| P6 | 约束方向沿 z | **推压阶段 0°**；后退阶段最大 0.023°（见发现 3） | 推压 ✓，后退有小偏差 |
| P7 | 接触点不漂移 | **推压阶段只作用在中心节点上（权重 1）**，侧向位移 ≤ 6.5e-7 m；后退阶段邻近节点权重最大 7.4e-4（见发现 3） | 推压 ✓，后退有小偏差 |
| P8 | 实时（R3） | 往复 2000 步：中位数 4.43 ms，p95 6.04 ms，最大 7.15 ms，没有一步超过 dt。GUI 场景（batch）：计算 + 绘制平均 5.6 ms，p95 7.5 ms，有效实时比 1.001 | ✓ |
| P9 | 网格依赖（静态，中心节点给定位移） | 见发现 5：**刚度 ∝ h，不收敛**；细网格在压深 ≳ 2h 时单元翻转 | 预测得到证实 |
- P5 的小正偏差，一部分来自静力参照表的线性插值：F(δ) 是向下弯的，1 mm 间隔上线性插值会低估约 0.17%（按曲率估算），和最慢工况的 +0.15% 吻合；速度和 dt 增大时偏差略增，是动力学效应。
- 0c 的两个待确认项已经确认：
  - ① 接触法向的朝向：`Tetra2TriangleTopologicalMapping(flipNormals=False)` 提取的顶面，`PhongTriangleNormalHandler` 给出的法向是 (0, 0, −1)，**指向组织内部**；`SecondDirection` 取反后 n = (0, 0, +1)；δ = n·(P_针 − P_组织) > 0 表示分开，δ < 0 表示穿透，和 `UnilateralConstraintResolution`（λ ← λ − d/W，截断到 [0, max]）一致〔运行 + 代码〕。
  - ② 组织侧约束力的读法：从约束直接建立的那一层 MO（表面 MO）的 J 和 λ 读出。不能把体 MO 也加进来，因为约束行会经 `IdentityMapping` 映射到体 MO，两层都加会重复计数。准静态时它和底面反力相差 5e-6。

## 发现

### 发现 1：规则网格的切分方向造成约 30% 的侧向漂移 → 测试台改用 swapping=True〔运行〕
- 冒烟测试中，针尖竖直压在中心节点上，中心节点却沿对角线侧向漂移（压深 6 mm 时漂移 (−1.42, −1.42) mm），接触点离开节点，针受到侧向力。
- 静力检验（中心节点给定 z 位移，x、y 自由）：

  | 网格 | 压深 1 mm | 压深 6 mm |
  |---|---|---|
  | n = 9，swapping=False | 侧向漂移为压深的 31% | 33% |
  | n = 17，swapping=False | 32% | 26% |
  | swapping=True | 0 | 0 |
- 原因：`Hexa2TetraTopologicalMapping` 在 swapping=False 时每个六面体按同一方向切成 6 个四面体，网格刚度不对称；swapping=True 时相邻六面体的切分方向交替，网格在中心节点处镜像对称。
- 处理：第 1 步的测试台用 swapping=True（`contact.add_tissue_with_surface` 默认）。`common.add_tissue` 的默认值仍是 False，0a–0d 的结果可以原样复现。
- 附带结论：对称网格下，四分之一模型和全模型的结果完全相同（P9）。0a-2 里两者相差的几个百分点，就是原来不对称切分造成的。
- 对第 1.5 步的提醒：非结构化网格局部不对称，无摩擦接触时接触点同样可能漂移。

### 发现 2：顶点接触的力–深度曲线（测试台，ν = 0.45，E = 5 kPa）
- 静力解：δ = 1 / 5 / 10 mm 时 F = 0.073 / 0.323 / 0.518 N；割线刚度从 73 N/m 降到 52 N/m（几何非线性）。

### 发现 3：后退时，插件的"最近点投影"在漏斗形凹坑里不稳定〔运行 + 推论〕
- 推压阶段接触点精确落在中心节点上；后退阶段，接触点每一步在漏斗两侧壁之间来回跳：邻近节点权重 ≤ 7.4e-4（慢速），约束方向倾斜 0.023°，左右交替。
- 机理：控制器在步首先把针尖上移，组织还在上一步的位置，针尖悬在漏斗底的正上方；从漏斗底正上方一点到漏斗表面的最近点在侧壁上（距离 H·cos θ < H），而不在漏斗底。
- 快速后退（50 mm/s）时看到"针尖比节点高约 0.2 mm 而 λ > 0"，也是这个原因：针尖压在比漏斗底高约 0.2 mm 的侧壁点上，邻近节点权重约 3%。而且组织回弹（约 10 mm × 44 rad/s ≈ 0.44 m/s）比 50 mm/s 快，组织一直追着针尖，λ > 0 在物理上是对的。所以 P3 改用 1 m/s 检验分离。
- 影响：推压阶段没有影响；后退阶段在慢速下影响很小。但它是插件"每步重新找最近点"在深、窄凹坑中的算法缺陷。
- 候选改法（2026-10-01 按复核意见修改；第 2 步之前决定）：
  - 第 1 步是**无摩擦**接触，所以优先考虑和切向滑动兼容的做法：沿针轴方向投影代替最近点投影；或者持续跟踪接触，但仍允许无摩擦的切向滑动。
  - "接触建立后固定同一个材料点"隐含了切向粘着（摩擦），和无摩擦的假设矛盾，只在引入刺穿前摩擦时才考虑。
  - 注：用户指出的物理现象（回撤时组织贴着针尖、针尖在漏斗最低点）只要求法向贴合，在每一步结束时的结果中是成立的：慢速回撤 999 步全部 λ > 0，步末针尖比漏斗底高 1–6 µm。偏差只来自步首找接触点的时机。

### 发现 4：点接触的刚度还取决于针尖落在网格的哪个位置〔运行〕
- 同一网格、同一压深范围：针尖落在顶点上 k = 74.8 N/m；落在三角形内部（权重 (0.7, 0.15, 0.15)、(0.45, 0.3, 0.25)、(0.6, 0.2, 0.2)）时 k = 106–124 N/m，**高出 43%–66%**。原因是力分摊到 3 个节点上。

### 发现 5（P9）：点接触的刚度和网格尺寸成正比，不收敛；细网格上单元会翻转〔运行 + 推导〕
| 模型 | h | 节点数 | k（压深 1 mm） | k / h | 最差单元体积比（压深） |
|---|---|---|---|---|---|
| 全模型 / 四分之一 | 10 mm | 729 / 225 | 72.9 N/m | 7.3e3 N/m² | 0.98（1 mm）、0.53（10 mm） |
| 全模型 / 四分之一 | 5 mm | 4913 / 1377 | 36.2 N/m | 7.2e3 N/m² | 0.95（1 mm）、0.52（5 mm）、**−0.64（10 mm）** |
| 四分之一 | 2.5 mm | 9537 | 17.0 N/m | 6.8e3 N/m² | 0.89（1 mm）、0.68（2 mm）、**−0.64（5 mm）** |
- **网格每加密一半，刚度减半**，k ≈ 1.45·E·h。和"理想点载荷下方的位移在连续体中是无穷大"的推导一致：点接触的刚度是离散量，没有网格无关的极限。
- 细网格上，单个节点被压到约 2h 以上时，下方的单元**翻转**（体积比为负，polar 分解报零行列式）。
- **对第 1.5 步的结论（2026-10-01 按复核意见修改）**：
  - 已经证明的是：**单个数学点不能用于定量的接触刚度**。所以需要**有限支撑**的针尖表示，并让针尖附近的单元和支撑尺寸相当。这和"针的直径是影响刺穿力最大的因素"（离线有限元文献，`step1_tenting_survey.md`）一致。
  - **具体形式还没有定**：多点圆盘、斜面 / 三棱针（TU Delft 数据用的是 18G 三棱套管针）的代理几何、接触面片等，在第 1.5 步先做复用优先的比较再定。注意：针尖形状的亚毫米细节在实时预算的网格（针尖附近最细约 1 mm）上本来就分辨不出，比较时先看支撑尺寸和加密后是否收敛。
  - **单元翻转要区分两个问题**：① 接触奇异性（点载荷让变形无限集中），有限支撑会明显缓解；② 大应变下材料模型是否还有效：线性四面体加共旋线弹性在大的局部压缩下本身就不是合适的组织模型（ν = 0.45 时还有锁死倾向），**有限支撑不会自动解决**，属于以后物理验证和参数辨识阶段的问题。

### 发现 6：R3（异步分解）偶发的单步尖峰〔运行〕
- 往复工况下 R3 和 R1 的针根力：相对差的中位数 1.7e-5，p95 2.2e-4，最大 2.3%（单步，出现在第一次推压的中途，不在接触开始或方向反转的时刻）。符合"偶尔用到较旧的分解"的特点。实时演示可以接受；定量验证按既定策略用 R1。
- **更新 R3 误差的认知**：0d 测得的瞬态差别是 ≤ 0.5%（dt = 0.01），但接触动力学中观察到**偶发的单步差别可达约 2–2.3%**，中位数和 p95 很小。不再把"瞬态约 1% 以内"当作普遍上限。

### 发现 7：A2（SOFA 自带的拉格朗日接触）：尝试过，在当前配置下没有运行起来，结论不确定〔运行〕
- 按 probe–tissue 教程的配置（碰撞流水线 + `LocalMinDistance` / `MinProximityIntersection` + `FrictionContactConstraint`），在纯运动学针 + v25.12 下能生成约束行，但不产生接触力。试过去掉锥角过滤、换邻近检测方法、针尖初始就压入、翻转表面法向，都没有效果。A2 是可选的轻量检查，按时间上限停止，原因没有查清。
- A2 既不构成"验证失败"，也不构成对 A1 的支持。第 1 步的结论依靠的是另外两套参照：P1a（SOFA 自带的双边约束，不经过插件的检测、法向和投影，一致到 7e-15）和 P2（同一雅可比的参照，一致到 0.05%）。

### 发现 8：场景构建的一个陷阱（我自己的错误，已改正）
- GUI 场景第一版把显示模型（`OglModel` + 第二个 `IdentityMapping`）加在了表面接触 MO 所在的节点里。**SOFA 一个节点只允许一个状态对象和一个映射**，后加的会替换先加的。结果接触用的表面 MO 和映射被替换，接触柔度变成 0，λ = 1.8e308，插件随即把它判为刺穿，接触被清除。
- 改正：显示模型放在单独的子节点里。教训：读接触力之前先确认没有这类"替换"警告。

## 第 1 步的结论
- **刺穿前的单边接触机制正确**：
  - 和完全独立的 SOFA 双边约束一致到机器精度（P1a）；
  - 和同一离散雅可比的参照一致到 0.05%（P2）；
  - 只推不拉、作用力 = 反作用力、不依赖 dt 和速度、实时都满足。
- 留给后面的事项：
  1. 后退阶段最近点投影的不稳定（发现 3）：**第 2 步之前**选定接触跟踪策略（无摩擦时优先轴向投影或允许滑动的持续跟踪）；
  2. 点接触刚度不收敛、刚度依赖针尖位置（发现 4、5）：第 1.5 步先做"有限支撑针尖表示"的复用优先比较，再和非均匀网格一起设计；
  3. 单元翻转中的材料有效性部分（发现 5）：物理验证 / 参数辨识阶段；
  4. 网格各向异性（发现 1）：**每个工作网格的固定验证项**：局部加载下检查人为的侧向漂移。
- 用户 GUI 目测（2026-10-01）：看到针、凹坑随针出现和恢复，过程流畅。**第 1 步机制验证通过（用户和 ChatGPT 复核后确认）。**
