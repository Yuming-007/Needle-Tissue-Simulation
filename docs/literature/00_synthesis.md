## 3. 互相印证的结论（可信度高）

1. **约束法（Lagrange 乘子）+ 不重划网格是 SOFA 生态里的主流做法**：Duriez 2009、Martin、Bui、CollisionAlgorithm 都是这样。Chentanez 批评它"针附近的应力不准"，但对力和轨迹来说足够了。
2. **穿刺前**：针尖和表面之间用单边约束 + 阈值 → **刺穿（rupture）= 力学状态切换，不改拓扑**。所有约束法的论文都是这么做的。
3. **穿刺后**：每个约束点 = 2 个横向双边约束（针身沿针道走）+ 1 个轴向摩擦约束。
4. **摩擦按单位长度参数化**：DiMaio（力密度 N/m）、Okamura（D、C、b 都是单位长度的）、Chentanez（f_perlen）、Duriez（lπd·r）、van Gerwen（力沿针身近似均匀分布）。
5. **多层组织 = 按层切换参数**：Duriez（每层 f_p、f_c）、Chentanez（f_cut 按区域取，界面附近取大值）、DiMaio（每层的力密度不同）、van Gerwen（每穿过一层断裂韧性更低的组织，就出现一次峰值和骤降）。
6. **力的量级**：单根针 0.1–10 N（穿刺约 1–2.3 N，切割约 0.9 N，摩擦约 0.3–1 N / 5 cm）。
7. **约束点间距**不能小于组织单元尺寸，否则 GS 会过约束，不收敛（Martin 2023 表 2）。
8. **线弹性共旋**几乎是所有实时方法的选择（Duriez、Martin、Bui）；只有 Chentanez 用了非线性（可反转 FEM），Wang 用了 Ogden。

## 4. 矛盾或者存疑的地方（需要我们自己判断）

| 问题 | 说法 A | 说法 B | 我的判断 |
|---|---|---|---|
| **针身摩擦和速度的关系** | Martin："强烈依赖速度，纯 Coulomb 不合适"（η 型） | Okamura 2004：mm/s 量级下 Coulomb 项占主导；van Gerwen：生物组织 2 mm/s 以上对速度不敏感；仿体材料才明显随速度增加 | 机器人慢速插针（1–10 mm/s）时，**Coulomb 或"静摩擦 + 动摩擦"就够了**；Martin 的结论主要来自仿体和 haptics 的需要 |
| **有没有切割力** | Duriez（f_c）、Bui（λ_c0）、Chentanez（f_cut）、Okamura（0.94 N，比摩擦还大）：有 | Martin 论文：没有切割力，只有摩擦 | **需要切割力**（有实验依据），否则力曲线的形状和多层组织的特征都不对 |
| **摩擦参数有没有物理意义** | Martin 的 η、λ_maxstick：依赖 h 和 W，没有物理量纲 | Bui 的 μ × 横向约束力；DiMaio/Chentanez 的 f_perlen × l | 优先用**有物理意义的参数**（μ 或 N/m），才能用 Okamura 这类数据标定 |
| **网格对力的影响** | 多数论文默认网格"够细" | Bui 2018：粗网格和细网格的力相差 2 倍（立方体）到 3.5 倍（肝脏仿体，图 16），而且"细网格"本身也还没收敛 | **标定参数前必须做网格收敛性测试** |
| **贴合网格还是约束插值** | Chentanez：针附近的应力场必须用贴合网格才准 | Duriez/Martin：约束插值就够了 | 对我们的目标（轨迹、力、组织形变）来说，约束法足够；如果以后需要"组织损伤"之类的局部指标，再重新考虑 |

## 5. 对项目设计的直接影响

1. **起点**：CollisionAlgorithm + ConstraintGeometry（它实现的是 Duriez / Martin 模型）。但要**逐项核对**：
   - [ ] 约束点是固定间距还是网格相交？
   - [ ] 双边约束的方向是按针的边还是按轨迹（Martin §5.4.2）？
   - [ ] `frictionCoeff` 是 Coulomb（μ × 横向力）、η 型，还是粘滑型？
   - [ ] 有没有切割力或针尖切割约束？
   - [ ] 能不能处理多个组织体，或者一个组织体里的多个区域？
2. **两种组织的立方体**，两种做法：
   - (a) 用**两个独立的组织体**，各带一个 `InsertionAlgorithm`（最接近插件现在的设计）；
   - (b) **一个组织体、按单元分区赋予材料参数**（CutFEM 思路的简化版），同时把穿刺和摩擦参数改成按区域取值（需要改代码）。
   - **参数**：用 Wang 2025 的双层 plastisol（E 约 5.5 / 11 kPa）或者 Okamura 的牛肝。
3. **针模型**：先用 BeamFEM 加大 E（刚性针），再用真实的 E（柔性针）。Cosserat 是可选项（Manish 提到过），等需要时再评估。
4. **斜面针尖**（柔性针阶段）：Chentanez 的针尖横向偏移，或者 Wang 的预压缩弹簧 → 在 SOFA 里可以通过**针尖路径约束的方向倾斜**来实现（Duriez 2009 §2.4）。
5. **速度和接口**（为规划和控制做准备）：
   - 准静态格式（Martin 第 5 章）；
   - 能用 Python 一步步推进，能保存和恢复状态，能多进程并行；
   - 输出：针尖位姿、针的形状、针根的力、每层的应变能、到关键结构的最小距离（SDF）；
   - 性能手段：粗网格、`PrecomputedConstraintCorrection`、ModelOrderReduction（**沿预定轨迹局部降阶**，Vanneste 2024）、混合求解器（可以自己实现）。
6. **验证**：
   - 力曲线的定性形状（Okamura：二次上升 → 骤降 → 线性增长，拔出时变负）。注意：**约束法仿真能不能再现"刺穿后骤降"并不一定**：Duriez 2009 的 Fig. 6 里没有骤降，Bui 2019 的图 25 里有（阈值穿刺之后，针尖切割强度更低）；
   - 力的量级（van Gerwen）；
   - 网格收敛性（Bui 2018）；
   - 非均质组织中针的偏转和刺穿情况（Duriez 2009 图 8、Bui 2019 图 25）；
   - 靶点因组织形变而偏移（DiMaio 2003 图 17）。

## 6. 自测：阅读前我答不好的几个问题

**Q1. Martin 的混合求解器具体怎么拆分双边约束和摩擦约束？IsoDOF 在什么条件下会失效？**
- 拆分：把所有双边约束排在 H 的最前面，W 就分成 $\begin{pmatrix}W_b&W_c\\W_c^T&W_f\end{pmatrix}$。每次迭代先用**伪逆**直接求 $\lambda_b=W_b^+(-\delta_b^{free}/h^2-W_c\lambda_f)$（伪逆每次求解只算一次），再对摩擦约束逐个做 GS 更新，然后乘以 η。用伪逆，是因为约束点挨得近的时候 W_b 是病态的。
- IsoDOF 的局限：
  ① 要求**受约束的自由度远少于总自由度**（H 稀疏）。粗网格加上大面积接触时，H 不再稀疏，优势就没了（论文 §4.2.1 提到的"粗糙体"不用它）；
  ② 依赖**异步预条件器**：A⁻¹ 在更新的那几步里是旧的，形变大、变化快时会不准（图 4.6 中更新时的性能尖峰）；
  ③ 只对**被穿刺的精细体**有意义；
  ④ 实现依赖 GPU 和私有代码。

**Q2. Okamura 的修正 Karnopp 摩擦模型，参数怎么映射到 SOFA 的约束阈值上？**
- Okamura 的参数是**单位接触长度**的：D（静摩擦，N/m）、C（动摩擦，N/m）、b（粘性，N·s/m²）。
- 映射：约束点 i 负责针长 $l_i$（大约等于约束点间距 d，或者等于网格相交法里相邻交点之间的距离）。于是：粘着阈值 $=D\,l_i$；滑动力 $=(C+b|v_{rel}|)\,l_i$，其中 $v_{rel}\approx\delta_f/h$。
- 在约束求解里：先按双边约束求出 $\lambda_{f,b}$，如果 $|\lambda_{f,b}|\le D\,l_i$ 就是粘着；否则 $\lambda_f=-\mathrm{sgn}\cdot(C+b|v|)\,l_i$（这就是 Duriez 2009 图 4 那条带斜坡的特征曲线，也是 DiMaio 2003 的"粘着时位移约束 / 滑动时恒力"）。
- 这是一个**有物理量纲、可以标定**的形式，比 Martin 的 η 更好。代价是：因为和速度有关，需要知道 h。
- 另一种选择是 Bui 的 Coulomb 形式：$|\lambda_f|\le\mu|\lambda_{\perp}|$，**正压力直接来自仿真里的横向约束力**，参数是无量纲的 μ。但 μ 和 Okamura 的 N/m 参数不能直接换算：需要知道横向约束力有多大，而这取决于组织刚度和针的直径。
- **我们选哪种，要看 CollisionAlgorithm 的实现，再做决定。**

**Q3. Chentanez 的 stick-slip LCP 和 Duriez 的 GS 做法有什么本质区别？各自在速度和精度上怎么取舍？**
- **Chentanez**：把针和组织**放在同一个大线性系统里**（式 7，对称不定），**猜测每个节点的摩擦状态**（组合问题），然后用 CG 解大系统，检查互补条件，猜错了就换状态再解（平均 1.2 次，最多 10 次）。
  - 精度：每一组状态都**精确求解**（在 CG 的容差之内），接触力和网格一致（网格贴合）。
  - 速度：每次猜测都要解一个**完整规模**的系统；状态变化频繁时（比如从插入变成拔出）要试很多次；**时间不可预测**。
- **Duriez**：**先把问题投影到约束空间**（W = HA⁻¹Hᵀ，规模只有约束数那么大），在这个小系统上用**非线性 GS 逐个约束**求解，摩擦状态在迭代中自然确定。
  - 速度：每次迭代只是约束空间里的小运算；可以**提前终止**，时间可控（适合 haptics）；但要先算 W，这需要 A⁻¹，是主要开销。
  - 精度：GS 收敛慢，尤其在约束多、病态、双边约束和摩擦混合时（Martin 2023 表 2）；提前终止的误差不均匀，会沿针道累积（Martin 第 6 章）。
- **本质区别**：Chentanez 是"**状态枚举 + 全系统线性求解**"；Duriez 是"**约束空间 + 局部非线性投影迭代**"。前者的矛盾点在"状态组合"，后者的矛盾点在"W 的构造和 GS 的收敛"。

**Q4（新增）. 为什么 Bui 2018 里粗网格和细网格的力会差 2–3.5 倍？这对我们意味着什么？**
- 线性四面体在针附近表达不了高梯度的位移场（位移在单元内是线性的）→ 粗网格的组织在局部"更硬"（数值上的锁死效应）→ 同样的针位移下横向约束力更大 → Coulomb 摩擦（μ × 横向力）更大 → 轴向力更大。
- 意味着：**参数和网格是绑定的**。用实验数据标定 f_p、μ 之前，要先固定网格密度，或者做网格收敛性研究；规划用的粗网格仿真和验证用的细网格仿真，参数不能混用。

## 10. 补充阅读改变了哪些判断

| 之前的判断 | 补充阅读后 |

| 最终目标"规划 + 控制"没有 SOFA 先例 | **控制部分有完整的先例**（T-RO 2019 到 ICRA 2026）；**规划部分在 SOFA 里没有先例**（Wang 2025 用的是 2D 自研仿真器） |
| 速度的主要手段不清楚 | ① 粗网格已经够控制用（几百到几千个节点）；② **瓶颈是 W 的计算（占 70–80%）**；③ 在一步之内用约束空间做扰动（W 只算一次）；④ 分区降阶（开源）；⑤ 用神经网络学习仿真数据 |
| 验证只能做定性对比 | ① 合成验证（直接仿真 vs 逆向仿真，这一派的标准做法）；② **JHU 的多层 plastisol 仿体 + CT 重建的针形状**（Wang 2024）→ 可以做 SOFA 模型的物理验证，正好回应 Wang 2024 对 SOFA 路线"缺乏验证"的批评 |

## 11. 本项目可能的定位（供讨论）
把两派的缺口放在一起看：
- Strasbourg 派：3D 体网格 SOFA + 控制，但**组织均质、没做规划、没有物理验证**；
- JHU 派：多层组织 + 斜面针 + 规划和控制 + 仿体验证，但**是 2D 的，组织不是体网格**，描述不了刺穿前的形变（Wang 2025 自己指出了这一点）。

→ **本项目的自然定位**：**在 SOFA 里做 3D 多层组织的针插入仿真**（复用 Strasbourg 的约束框架和 CollisionAlgorithm），**用 JHU 的多层仿体数据做验证**，并且**提供面向规划和控制的接口**（批量运行、保存和恢复状态、敏感度或 Jacobian）。两个月里做到"刚性针 → 多层 → 柔性针 + 验证"是现实的；规划和控制本身可以作为展示用例，或者留作后续工作。

## 14. 核对后的更正（2026-09-30，19 份笔记逐篇对照原文核对之后）
- 每篇笔记末尾都有"核对记录"，写明改正了什么、补充了什么。对综合结论有影响的有：
  1. **"刺穿后力骤降"不是约束法仿真的必然结果**：Duriez 2009 的 Fig. 6 里只有陡升，没有骤降（原笔记写的"穿刺峰值"不准确）；Bui 2019 的图 25 有（先按穿刺强度 λ_p0 刺穿，之后按更低的切割强度 λ_c0 前进）。→ 如果想再现 Okamura 那种骤降，需要**穿刺阈值 > 之后的针尖切割阈值**。
  2. **网格依赖比原来估计的更严重**：Bui 2018 图 16（肝脏仿体）中粗网格和细网格的力相差约 3.5 倍，而且拔出阶段的差别小得多。
  3. **DiMaio 的"针尖后峰值高约 100%"只在 1 mm/s 时成立**，3 mm/s 时约 19%，9 mm/s 时几乎为零。**随速度变化的是针身摩擦（34 → 80 N/m），针尖峰值基本不变（68 → 81 N/m）。**
  4. **Adagolodjo 2019 的 μ_n 原文叫"penetration resistance coefficient"**（0 = 无摩擦，1 = 粘着）→ 进一步证实这一派的摩擦参数是"占粘着力的比例"。
  5. **W 的写法至少有三种约定**：Duriez 2006（未知量是位移）、Martin 第 3、4 章（动力学格式，W 带 h²）、Martin 第 5、6 章和 Adagolodjo（准静态格式，W 不带 h²）。**比较不同论文里 W 的数值或 η 的取值之前，要先统一约定**（待方法手册统一）。
  6. van Gerwen 的表 3 必须区分仿体（Art）和生物组织（Bio），原笔记把两者混在了一起（已改正）。

## 15. 资源学习阶段的结论回填（2026-09-30）
§5.1 的核对清单和 §13 的技术核对，已经由代码阅读和实验回答（详见 `docs/code/01–04`）：
- [x] 约束点生成：**固定间距**（`tipDistThreshold`），沿针身方向；不是网格相交法。
- [x] 双边约束方向：**按针的边**（`FirstDirection` + `EdgeNormalHandler`），沿针身分段为常数。
- [x] 摩擦形式：**不是**物理摩擦律，而是 GS 轴向欠松弛（问题 1）。
- [x] 切割力：**没有**。
- [x] 多个组织体 / 多区域：一个算法实例对应一个表面和一个体网格；体网格内可以逐单元设材料（SOFA 原生）；层间界面不触发刺穿。
- [x] ModelOrderReduction 里的分区降阶：**公开仓库里没有**。
- 另外新增的关键事实：SOFA 的 λ 是冲量（一阶 / 二阶积分器混用会导致作用力 ≠ 反作用力）；约束间距 ≪ 单元尺寸时 GS 永不收敛；刺穿深度强烈依赖网格；官方求解配置的耗时约按节点数的 2 次方以上增长；进程分叉快照可以用于规划采样。
