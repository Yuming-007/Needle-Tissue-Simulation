## 1. IROS 2024：孤立目标约束（iso-constraint）

### 1.1 问题
- Baksic 2020 的"约束型目标函数"要把目标函数**线性化后放进 H** → 非线性目标函数（比如角度）不准，这在呼吸运动这类动态场景下会影响稳定性。
- Adagolodjo 2019 的做法需要投影回运动空间（$\mathbf A^{-1}\mathbf H^T\lambda$），开销大。

### 1.2 目标函数（§III-A）
$$\mathbf T=(e_x,e_y,e_z,\theta_1,\theta_2,e_{rcm_x},e_{rcm_y},e_{rcm_z})^T\quad(7)$$
- $\mathbf e_p$：针尖到轨迹上目标点的偏差；
- $\theta_1$：针尖方向和轨迹切向之间的夹角；$\theta_2$：针根方向和"针根 → 进针点"向量之间的夹角（这两个角都小，针就弯得少，对器官的应力也小）；
- **进针点 RCM**（3 自由度）：让进针点保持不动（把初始进针点投影到针身上）→ 防止撕裂皮肤。结合初始轨迹目标，机器人会**绕进针点转动**来跟随呼吸。

### 1.3 孤立约束空间（§III-B）⭐
- $\mathbf H_O=\hat{\mathbf H}_O\bar{\mathbf I}_O$：只选出和目标函数有关的自由度（针根、针尖、RCM 投影点），$\bar{\mathbf I}_O$ 是部分单位阵（**和 IsoDOF 的思路一样**）。
- 施加约束力 λ 之后，**直接积分这些自由度的位置**：$\mathbf x_{iso}=\mathbf x^{free}+\mathbf W_O\lambda h$（式 8），$\mathbf W_O=\sum\mathbf H_O\mathbf A^{-1}\mathbf H^T$ 是约束力和孤立自由度位移之间的耦合算子。
- → 用这些**真实的位置**去算目标函数，可以是**任意非线性的**，不需要线性化。
- $\mathbf W_O$ 在每步开始时只算一次（和 W 一起，可以用 GPU）。
- 算法 1：W 和 W_O 各算一次 → 对每个自由度 j 和 k ∈ {−1, 1}：解约束 → 积分 x_iso → 算目标函数 → 中心差分 → 伪逆 → 发给机器人。

### 1.4 实验
- 针：13 个节点，E = 200 GPa，ν = 0.3，半径 0.723 mm；50 Hz，时间步 0.02 ms（原文如此，应该是 0.02 s）；针根笛卡尔速度 50 mm/s，旋转 0.2 rad/s；目标沿轨迹以 2.5 mm/s 前进，约 30 s 到达肿瘤。每种情况 50 次。
- **人体模型**（3D-IRCADb-02，CT，带呼吸周期）：肝脏 E = 8 kPa，ν = 0.4（网格 498、1000、1500 个节点）；皮肤 1836 个三角形，E = 20 kPa，ν = 0.3；**直接仿真**充当真实环境，**逆向仿真**是它的缩小版。
- **结果**：
  - 7.5 cm 的曲线轨迹：终点误差 0.5 mm（Baksic 2020 是 2.0 mm），角度误差 0.08–0.13 rad（对比 0.18），组织应力 0.6 MPa（对比 1.0）；
  - 人体呼吸场景：精度提高 0.6–1.5 mm，平均误差 1.0 mm（对比 2.25 mm）；
  - **计算时间**（表 I，Ryzen 9 5900X + RTX 3070 Ti，**SOFA + Assist + ROS2**）：网格 500 / 1000 / 2000 个节点时，一步分别是 4.88 / 9.09 / 21.07 ms（Baksic 的方法 5.57 / 10.64 / 24.43 ms）。机械矩阵的定义（MM，第 1–4 行）占 74–82%。

## 2. ICRA 2026：用学习样例法代替逆向仿真

### 2.1 思路
- 逆向 FE 每步需要 12 次约束求解来算 Jacobian，放到真实机器人上会有延迟。
- **离线**用逆向 FE（iso-constraint 方法）生成大量数据 → **训练神经网络直接从"状态 + 目标误差"映射到机器人的位移指令** → 在线时网络几乎瞬间给出结果。

### 2.2 网络与数据
- **输入**：14 维 = 末端位姿 $\mathcal X_{pose}$（6 维）+ 目标函数值 $\mathcal T$（8 维，同上）；**输出**：末端位移 $\Delta\mathcal X$（6 维）。
- 可变形凝胶：普通的全连接网络（3 层，每层 512）；人体：**残差全连接网络**（3 个残差块，每块 2 层 256）。
- **数据**：
  - 凝胶：在最右侧部分均匀取 500 个靶点，一个进针点；两种初始针姿（垂直于表面，以及沿着轨迹方向）；
  - 人体：肿瘤周围 500 个"伪肿瘤"点；轨迹分两段（皮肤 → 肝脏表面 → 肿瘤）；数据采集时同时模拟呼吸；
  - **每个场景 100 万个样本**（75% 训练、15% 测试、15% 验证）；RMSE 损失，用 StandardScaler 做归一化。
- 训练结果：凝胶损失从 0.45 降到 0.21，肝脏从 0.20 降到 0.07。

### 2.3 结果
- **凝胶**（每种轨迹 200 个随机靶点，距离 10 cm）：直线轨迹 MLP 0.12 mm，和 iso-constraint 相同，比 obj-constraint 的 0.24 mm 好；曲线和移动轨迹也好于或相当于数值方法。
- **计算时间**（表 II，网格 1000，约束间距 10 mm）：iso-constraint 一步：MM 7.17 ms、逆向 0.92 ms、FE 1.0 ms；**MLP：MM 5.04 ms、逆向 0.26 ms、FE 1.56 ms** → **逆向部分减少了约 70%**，但**总时间仍然主要是 MM（机械矩阵定义，也就是 W 的计算）**。
- **人体**（肝脏 498 个三角形，E = 8 kPa；皮肤 E = 20 kPa；UR3e 机器人通过 ROS2 和笛卡尔控制器接入，考虑了机器人的延迟）：沿途误差更小，终点误差 < 1 mm，好于 iso-constraint。
- **局限**：轨迹是直线，肝脏是均质的，没有血管；材料参数太简单；**还是需要前向仿真来提供网络的输入**（需要分割和重建）；机器人的动力学还没有完全考虑。

## 3. 和本项目的关系
1. **这条工作线（2016 → 2026）就是 Manish 最终目标在 SOFA 生态里的"标准答案"**：SOFA 约束法针插入仿真 + 数值 Jacobian（逆向 FE）+ 机器人闭环控制 + 学习加速。用的都是**线弹性共旋、Timoshenko 梁、几百到几千个节点**的粗网格 → 说明**粗网格对控制来说已经够用**。
2. **不同之处（我们可能的贡献点）**：
   - 他们都是**均质**组织（一个肝脏加一层皮肤）；**多层组织**（每层不同的穿刺和摩擦参数）没有系统研究；
   - 他们的目标是**跟踪给定轨迹**（局部控制）；Manish 的目标里还有**规划**（选出绕开关键结构的轨迹），更接近 Wang 2025 的 CE 规划；
   - 他们的验证都是**仿真对仿真**（直接仿真 vs 逆向仿真），没有物理模型验证（Wang 2024 批评的就是这一点）。
3. **速度的实际瓶颈是"机械矩阵定义"（W = HA⁻¹Hᵀ）**，占 70–80%。无论是逆向步骤的优化还是神经网络，都没有改变这一点 → 我们的提速重点也应该在这里（粗网格、预计算柔度、降阶、GPU）。
4. **"用仿真数据训练网络，代替昂贵的在线计算"**，是满足"速度"要求的另一条路：仿真器本身可以慢一些，只要能**离线大量生成数据**。这对仿真器提出的要求是：**能批量、无界面、可重复地运行**，并且能**方便地随机化**（靶点、参数、轨迹）。
5. 实现依赖 **Assist + ROS2 + SOFA**，Assist 正在逐步开源；这几篇的代码都**没有公开**。
