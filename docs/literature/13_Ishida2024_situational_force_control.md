## 1. 问题
- 侧颅底手术：钻磨不同密度的骨头，关键结构（面神经、乙状窦等）就在亚毫米距离之外；工具和组织之间的作用力可能低于人的感知阈值。
- 协作机器人（REMS，Galen Robotics，导纳控制）能消除手抖，但它的刚度和惯性会**削弱医生对作用力的感知**。

## 2. 方法
- **数字孪生**（Twin-S，Shu 2023）：由 CBCT 分割出的患者解剖模型 + 光学跟踪 + 钻头上的实时力传感（Chen 2023）。
- **判断当前正在操作的结构**：用**有符号距离场（SDF）**实时计算钻头尖端到每个解剖结构的最近距离 d_n；如果最近距离小于阈值 γ_n，而且力超过接触阈值，就把它识别为当前操作的结构（图 2）。
- **每个结构有自己的安全力阈值 λ_n**（表 1）：面神经、鼓室盖、乙状窦 0.8 N；皮质骨、松质骨 1.3 N。阈值来自两位主治医生的钻磨统计。
- **自适应导纳增益**（式 1–4）：
  - $\arg\min_{\Delta q}|\sigma(t)\,I\,G\,F_H-J\Delta q|$；
  - 没接触时 σ_high = 1.7（更"透明"）；接触后 σ_contact = 0.7；
  - 力超过 U = λ_n 后，σ 按 $\sigma(0)\exp(-\eta\Delta F(t-t_0))+\sigma_{low}$ **指数衰减**（σ_low = 0.3，η = 1.0）→ 机器人逐渐"变硬"，限制继续施力。
- **频率**：力传感器 200 Hz，机器人 500 Hz，**虚拟仿真 1000 Hz**。

## 3. 实验与结果
- 在尸体颞骨上，一名医学生和两名工程学生，在乳突切除术后围绕关键结构继续钻磨。
- 结果：使用这种控制后，大多数情况下作用力更小，超过安全阈值的时间比例显著下降（例如松质骨从 0.209 降到 0.042）；但有一名被试（P3）因为手眼协调差、动作突然，在部分结构附近力反而增加。
- 以后的工作：细化阈值、加入安全虚拟夹具（virtual fixtures，Ishida 2024 ICRA）、做更大规模的用户研究。

## 4. 和本项目的关系
1. **Manish 组的研究范式**：患者影像 → 分割出解剖结构 → 数字孪生 → 用**有符号距离场**判断工具和关键结构的距离 → 按结构调整控制策略。
   - 针插入的"**绕开关键解剖结构**"可以用同样的方法实现：在仿真里对每个关键结构算 SDF，把"针（尖）到关键结构的最小距离"作为**安全指标**或规划代价项（对应 Wang 2025 代价里的 O(X)）。
2. **"每个结构一套参数"**：本文每个结构有一个安全力阈值；我们的多层组织模型里，每层有自己的材料参数、穿刺力和摩擦参数 → **数据结构可以统一**：用一张"组织库"表（Simone 2002 的说法）。
3. **频率参考**：他们的虚拟仿真跑在 1 kHz（刚体 + SDF，没有形变）。对于有形变的针插入仿真，1 kHz 不现实；**需要问清楚 Manish 对"速度"的具体期望**：是 haptic 级别（1 kHz），交互级别（30–60 Hz），还是给规划用（远快于实时）。
4. 本文用 3D Slicer 做分割和标注 → 以后针对具体患者建模时，工具链可以沿用 3D Slicer（有 SlicerSOFA 扩展，待查）。
