## 1. 第 3 章：SOFA 里的 FEM 和针–组织交互（和 handbook §1 对照）
- 组织：共旋 Hooke（Felippa 2000），K̃ₑ = RₑKₑRₑᵀ，旋转由极分解得到（Nesme 2005）；针：Timoshenko 梁（Przemieniecki），Kₑ = ΛK̄Λᵀ。
- 时间积分（式 3.7、3.8）：((1 + hα)M + h(h + β)K)·dv = h(g − f) − h²Kv，Rayleigh 阻尼 B ≈ αM + βK，每步只做一次 Newton 迭代。
- ⭐ **λ 的量纲**（p.39，式 3.10）："λ 和动量同量纲（kg·m·s⁻¹），相当于在时间步 h 上积分的力" → **SOFA 的 λ 是冲量**，和 `docs/code/01` 问题 2 的代码分析、运行验证一致。
- 约束的原子类型（图 3.4）：双边、单边（Signorini）、**摩擦（把 λ 截断在一个上限）**。
- 针–组织模型（§3.3.3，图 3.6，基于 Duriez 2009）：①不接触：针尖和最近表面点之间一个单边约束；②刺穿前：单边约束 + 2 个摩擦约束，上限 μₙλₙ（Coulomb）；③法向接触力超过"破裂力"之后进入插入阶段：沿针每隔 dₙ 加一组约束，**2 个双边约束 + 1 个摩擦约束**，这个摩擦约束"同时表示固体摩擦和插针所需的切割力"。
- 求解（§3.4）：自由运动用共轭梯度 + GPU 上的异步 LDLᵀ 预条件器（Courtecuisse 2014）；W 用异步分解或者预计算的 A⁻¹（Saupin 2008，随时间越来越不准）；修正的 GS（算法 1，收敛判据是 ‖λᵏ − λᵏ⁻¹‖/‖λᵏ‖ < ε）；运动修正（"reprojection"）。
- **计时**（§3.5，图 3.8；针 13 cm、13 个单元、半径 0.723 mm、E = 200 GPa、ν = 0.3；gel 2000 个节点、9234 个四面体、E = 6 kPa、ν = 0.4；i7-7700HQ + GTX 1060 Mobile）：自由运动 12.1 ms（40.5%），定义约束（主要是 W）11 ms（36.9%），**GS 0.2 ms（0.5%，约 50 个约束，20 次迭代收敛）**，运动修正 6.5 ms（21.9%）。作者指出：**三个不共线的约束作用在同一个梁单元上时，问题过约束，GS 可能不收敛**。

## 2. 第 6 章：真实系统（KUKA iiwa 14 + Optitrack + 硅胶肝仿体）
- **针的标定**（§6.4.1）：活检针自由段 14 cm、外径 1.09 mm；在针尖挂不同重量，用 RGB 图像分割出针的弯曲，用**黄金分割法**搜索 E，使仿真弯曲和图像投影线的距离最小；20 个节点、19 个单元时误差最小（平均 0.35 像素）；**E = 77.94 GPa**，ν = 0.3。
  - 〔推导〕钢 200 GPa → 78 GPa 的差别可以用"空心针按实心截面建模"解释：E_eff = E(1 − (rᵢ/rₒ)⁴) ⇒ rᵢ/rₒ ≈ 0.88（薄壁）。Wang 2024 调参得到的 80 GPa 同理。→ **在 SOFA 里要么用 `radiusInner` 按真实截面建模，要么用约 80 GPa 的等效模量。**
- **针的配准**：两台 RGB 相机的立体投影约束（Zhang 标定 + PnP），同时估计针的初始弯曲形状。
- **仿体**（§6.3.3）：硅胶 40% + 软化剂 40% + 矿物油 20%（油用来降低摩擦），外面包一层纯硅胶模拟肝包膜；激光扫描得到几何后划分网格；质量 685 g。
- **仿体的标定**（§6.4.2）：带力传感器的球形压头竖直压入，在仿真里复现同样的压入（考虑重力和底面接触），用**二分法**搜索 E；ν 取 0.49（不可压缩，为了数值稳定不取 0.5）；**E = 7.237 kPa**，力的估计误差小于 0.05%。
- 呼吸运动平台（幅度约 3 cm，15 次/分钟）；皮肤用绷紧的硅胶膜模拟（提供远程运动中心）；ROS2 通信。

## 3. 和本项目的关系
1. **给"SOFA 的 λ 是冲量"提供了文献依据**，也说明他们这一派的场景里针和组织用的是同样的二阶积分器（没有一阶针的问题）。
2. **摩擦约束的正确写法**：把 λ 截断在一个上限（物理意义明确），而不是像 CollisionAlgorithm 那样只做欠松弛 → 和 handbook §2 写法 (a) / (b) 一致。
3. **两个参数标定方法可以照搬**：针用挂重法，仿体用压入法；都是"仿真复现实验 + 一维搜索"，只需要前向仿真。
4. **空心针的等效模量**：约 80 GPa（或者用 `radiusInner`）。
5. 过约束的警告（三个约束作用在同一个梁单元上）→ 约束点间距要考虑针单元的长度，而不只是组织单元的尺寸。
