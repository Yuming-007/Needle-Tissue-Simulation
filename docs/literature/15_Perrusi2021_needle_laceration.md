## 1. 区分两种"破裂"
- **穿刺（puncture）/ 插入**：针尖沿针轴前进，破开组织 → Duriez 2009 的穿刺阈值 f_p 加上插入约束，**不改拓扑**。
- **撕裂（laceration）**：已插入的针**横向**移动（比如呼吸运动、机器人刚性夹持），把针道周围的组织**切开**。临床上刚性机器人夹持时尤其常见。本文针对的是这一种。
- 观察：经皮手术中切口的范围有限，周围器官的挤压使组织不会真正分成两块 → **不需要真正的拓扑分离**，用一个"切割面"加约束就够了。

## 2. 基础模型（§3）
- 沿用 Duriez 2009：Timoshenko 梁（6 自由度）+ 线性四面体（Hooke）+ 共旋；隐式积分，一次 Newton 迭代；Lagrange 乘子；$\mathbf W\lambda=\delta^{free}$；GS 求解。
- **三种原子约束**：双边 φ（两个组合起来，限制点在两平面的交线上）、单边 χ（Signorini）、摩擦 ψ（粘滑）。
- 穿刺前：针尖和最近表面点之间 $(\chi_p,\psi_p,\psi_p)$，阈值 f_p。
- 插入：沿针道 $(\psi_i,\phi_i,\phi_i)$（1 个摩擦 + 2 个横向双边），针尖离所有已有约束点都超过 $d_i$ 时就新建一个约束点。

## 3. 切割 / 撕裂（§4）
- **撕裂判据**（式 3）：所有插入约束的横向力之和 $\|\mathbf t_i\|>n_i\cdot f_c$，其中 $\mathbf t_i=\sum\mathbf n_i^\phi\lambda_i^\phi$，n_i 是插入约束的数量，f_c 是切割力阈值（**平均的横向力**超过阈值）。
- **生成切割面**：对每个插入约束，在 $\mathbf p_t=\mathbf p_i+d_t\mathbf t_i$ 处生成一个点（沿横向力方向偏移 d_t）→ 用 **PCL**（Point Cloud Library）对点云三角化得到面 S（MLS 估计法向，贪心三角化，参数是最小角、最大角、面间最大角）。
- 切割阶段：**移除除第一个以外的所有插入约束**（保留第一个是为了防止表面被撕开）；改为对每个投影落在 S 内的针点加一个**切割约束** $(\phi_c,\chi_c)$：
  - $\phi_c$：针点和它在 S 上的最近点之间的**双边约束** → 针只能在切割面内滑动；
  - $\chi_c$：S 边界上的点和针身最近点之间的**单边约束** → 切割面边界挡住针。
- **扩展切割**：某个 $\chi_c$ 的力 $\lambda_c^\chi\ge f_t$（撕裂力阈值）时，切割面沿 $-\mathbf n_c^\chi$ 方向扩展 d_t。
- 切割面的点用**初始构型下的重心坐标**存储（式 4），保证三角化在变形过程中保持一致；再映射到当前构型上施加约束。

## 4. 结果（§5）
- 参数：d_i（插入约束间距）、d_c（切割面点间距）、E、ν、f_p、f_c、f_t、μ_p（表面摩擦）、μ_i（插入摩擦）。
- 立方体 10 cm³，3072 个四面体，E = 500 kPa，ν = 0.4；刚性针 32 cm，16 个梁单元，半径 0.8 cm，E = 100 GPa；f_p = 0.8 N，f_c = f_t = 1 N；d_c = d_i = 0.5 mm。
- 先插入 17 mm，然后针根横向移动 8 mm → 达到判据后组织开始撕裂。
- 性能（表 1）：穿刺阶段 1 个约束，15.1 ms；插入阶段 36 个约束，15.5 ms；切割阶段 12 个约束，12 ms。**约 65 FPS**。点云三角化平均 2 ms，但平均每 19.8 步才做一次。GS 在插入阶段平均 2.54 次迭代，切割阶段 80 次。
- 应用：肝脏在呼吸运动下的机器人插针。柔性针（E = 50 GPa）自己会弯，达不到切割阈值；刚性针（E = 200 GPa）在组织里产生大得多的应力，于是把组织切开，针沿切割方向滑动。

## 5. 局限
- 切割面是按当前的变形状态生成的，映射回静止状态时三角形之间的角度可能变化很大 → 变形大、运动快时，双边约束的方向会快速变化，造成不稳定；
- 达到阈值、切割面扩展时，力会突然下降（可以在切割面上加摩擦来缓解）；
- 参数没有经过标定（作者说以后可以用机器人上的力传感器数据来标定）。

## 6. 和本项目的关系
1. ⭐ **"rupture"至少有三种可能的含义**，需要和 Manish 确认：
   - (a) **穿刺时的破裂**：针尖刺破表面或层间界面（穿刺阈值 f_p，力学状态切换）→ 所有约束法论文都有，CollisionAlgorithm 已有；
   - (b) **沿针轴的切割**：针尖持续切开组织（切割力 f_c / λ_c0）→ Duriez 2009、Bui、Chentanez 有；
   - (c) **横向撕裂**：针横向运动把针道切开（本文）→ **只有这一篇**。如果机器人闭环控制中会横向推针（比如 Wang 2025 的 needle guide 横向平移、Adagolodjo 的针根横移），这一点就相关了。
   - Manish 原话"**当针尖和针杆逐渐进入组织时，组织发生破裂/撕裂**"，看起来主要指 (a) + (b)；"针杆"可能也暗示 (c)。
2. 本文说明：即使要做 (c)，**也不需要真正的拓扑修改**，用"切割面 + 约束"就能实现，而且保持在约 65 FPS。
3. 参数量级可以参考：f_p = 0.8 N，f_c = f_t = 1 N（和 Okamura 的 0.9 N 同一量级）。
4. 实现依赖 PCL 做三角化，是否开源不明（作者 Baksic 的博士论文 2022 可能有更多细节）。
